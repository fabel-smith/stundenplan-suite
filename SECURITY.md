# Security reports

Please do not publish passwords, tokens, school account identifiers, real school
schedules, children's data, or full Home Assistant configuration files.

Use [GitHub's private vulnerability reporting](https://github.com/fabel-smith/stundenplan-suite/security/advisories/new)
for suspected security vulnerabilities. If this option is unavailable, open an
issue containing only a request for a private contact method, with no sensitive
details. Regular bugs can be reported in public using fictional data.

Include the affected version and data provider, a minimal fictional example and
reproduction steps. Redact credentials and personal data from logs and screenshots,
even for a private report. Please test with the latest release. There is no
guaranteed response time or maintenance commitment for old releases.
